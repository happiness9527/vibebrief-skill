# Use Cases

## 1. You Do Not Understand What The AI Changed

Use Session Brief for a short plain-language explanation of the coding session.

## 2. You Need A Stage Summary

Use Milestone Report when a feature loop appears stable or a project phase may be ready to preserve.

## 3. You Need To Start A New Chat

Use Handoff Pack when a long AI coding thread is getting too large or the next agent needs compact context.

## 4. You Want A Visual Explanation

Use Visual Summary when a simple Mermaid diagram would make the situation easier to understand.

## 5. You Want Local Project Memory

Use Project Memory when a session should be saved under `docs/ai-worklog/` as a project asset.

## 6. The AI Says "Fixed"

Use Confidence Check when the AI claims completion but the evidence is unclear.

## Fictional Example Projects

Use fictional names in examples:

- TutorFlow
- DemoDesk
- SoloCRM
- CoursePilot

Do not publish real company names, customer details, credentials, or private project logs.
