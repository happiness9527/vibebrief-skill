# Roadmap

## V0.1

V0.1 focuses on the smallest useful open source skill:

- Session Brief
- Milestone Report
- Handoff Pack
- Visual Summary with Mermaid
- Project Memory under `docs/ai-worklog/`
- Light Acceptance Mode
- Lightweight helper scripts
- English and Chinese documentation

## Later

Possible later improvements will stay focused on clarity and installation quality:

- More agent-specific install notes
- More lightweight examples
- Better guidance for safe project memory
- Clearer compatibility notes for AI coding tools

## Not Planned For V0.1

- Frontend UI
- Third-party integrations
- Background daemon
- Automatic Git commit
- Automatic GitHub publishing
- Database service
- Product code modification
- Real automated test execution
