# Code Of Conduct

VibeBrief follows the Contributor Covenant spirit: be respectful, practical, and focused on improving the project.

## Expected Behavior

- Use welcoming and clear language.
- Respect different levels of technical experience.
- Keep discussions focused on the project.
- Give constructive feedback with specific examples.

## Unacceptable Behavior

- Harassment, insults, or personal attacks
- Sharing private information without permission
- Introducing credentials, tokens, or confidential project logs
- Repeatedly derailing technical discussions

## Enforcement

Maintainers may edit, hide, or remove contributions that violate this code of conduct. Serious or repeated violations may result in a temporary or permanent ban from project spaces.
