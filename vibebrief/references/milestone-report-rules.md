# Milestone Report Rules

Milestone Report is for stage-level summaries, not every small task.

## Trigger

Use this mode when the user asks whether a stage is complete, says a phase is stable, or wants a checkpoint before moving on.

## Required Sections

- Milestone name
- Stage goal
- Completed capabilities
- Key decisions
- Current stable capability
- Verified content
- Unclosed risks
- Snapshot recommendation
- Next-stage boundary
- Expansion items to avoid for now
- Copy-paste prompt for the next AI

## Snapshot Recommendation

Use one of:

- Save snapshot: core flow is verified and risks are known.
- Do not save yet: core flow is not verified.
- Unconfirmed: the input does not include enough evidence.

## Boundary Rules

A milestone is only meaningful if it has a clear boundary. If the next work is vague, propose one narrow next stage.

Examples:

- Good: "Next stage is login and basic profile editing only."
- Too broad: "Make the whole app production-ready."
