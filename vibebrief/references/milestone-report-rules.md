# Milestone Report Rules

Milestone Report is for stage-level summaries, not every small task.

Use this mode when the user asks whether a stage is complete, says a phase is stable, or wants a checkpoint before moving on.

Keep the report lightweight. It should help the user understand whether there is a clear stage boundary, what appears stable, what remains uncertain, and what should stay out of scope for the next step.

If the input does not include enough evidence, say that the milestone status is unconfirmed.
