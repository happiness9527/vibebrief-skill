# Handoff Pack Example

## Input

Fictional project: CoursePilot.

```text
I need to start a new chat. We built the course outline generator,
fixed the preview refresh bug, but export is not working yet.
```

## VibeBrief Output

**Project background:** CoursePilot helps creators generate and preview course outlines.

**Current goal:** Stabilize the outline preview flow before expanding export features.

**Current status:**

- Course outline generation exists.
- Preview refresh bug was fixed, but the provided input does not include verification evidence.
- Export is still unresolved.

**Recently completed:**

- Outline generator.
- Preview refresh fix.

**Current unresolved issues:**

- Export is not working.
- Preview fix needs proof if no test or screenshot exists.

**Key decisions:**

- Keep preview stability ahead of export expansion.

**Known risks:**

- The next AI may jump into export before confirming preview stability.

**Do not repeat these mistakes:**

- Do not add new export formats before one export path works.
- Do not treat "fixed" as verified without evidence.

**Prompt for the next AI:**

```text
You are continuing CoursePilot.
Project goal: help creators generate and preview course outlines.
Current status: outline generation exists; preview refresh was reportedly fixed but needs proof; export is still broken.
First, verify the preview refresh fix with the smallest manual or automated check.
Then debug one export path only. Do not add new formats or unrelated features.
Show evidence before saying the task is complete.
```
