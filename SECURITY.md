# Security Policy

## Supported Versions

VibeBrief is currently in V0.1. Security fixes apply to the latest public version.

## Reporting A Vulnerability

Please open a private security advisory if the hosting platform supports it. If not, contact the maintainer privately before posting exploit details in a public issue.

## Privacy Rules

Do not include:

- API keys or access tokens
- Passwords or private keys
- Real customer data
- Internal company names or private project paths
- Full private AI coding transcripts from real projects

Use fictional projects such as TutorFlow, DemoDesk, SoloCRM, or CoursePilot in examples and tests.

## Local Memory

The default memory path is `docs/ai-worklog/`. Public repositories should keep sensitive project notes out of version control. Use `docs/ai-worklog/private/` for private notes and keep it ignored.
